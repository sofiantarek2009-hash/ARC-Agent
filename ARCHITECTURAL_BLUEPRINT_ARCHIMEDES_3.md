# Architectural and Theoretical Blueprint for a First-Place Fluid-Intelligence Agent on ARC-AGI-3

## 1. Executive Architecture Thesis

The third generation of the Abstraction Corpus (ARC-AGI-3), launched on March 25, 2026 by the ARC Prize Foundation, shifts the evaluation of machine intelligence from static input-output grid completion to interactive, turn-based skill acquisition across unfamiliar environments. Whereas static benchmarks permit brute-force combinatorial search over candidate programs within a passive context window, ARC-AGI-3 reveals environment dynamics, object affordances, hazard mechanics, and win conditions exclusively through costly, state-altering interactions. Furthermore, the official scoring metric—Relative Human Action Efficiency (RHAE, pronounced "ray")—penalizes action inefficiency quadratically relative to first-exposure human baselines, weights later levels progressively more heavily, and enforces a hard termination cutoff at five times the human action budget. Under this regime, taking twice as many actions as the human baseline yields only 25% credit, and taking ten times as many yields a negligible 1%.

The central thesis of this dossier is that achieving first place on the hidden ARC-AGI-3 private evaluation set requires unifying two paradigms that have hitherto evolved separately in the 2026 competition landscape. The first paradigm is high-throughput local epistemic scaffolding, exemplified by Tufa Labs' Milestone 1 winning Duck harness and Daniel Franzen's Milestone 2 winning architecture (27.9% official public leaderboard score and 36.73% peak), which pair an open-weight hybrid Mixture-of-Experts model (Qwen3.8-Flash-Next) with SGLang prefix caching, intermediate animation exposure, frame-difference perception, undo recovery, retained Python workspace helpers, and dynamic cross-game compute scheduling under strict Kaggle hardware limits. The second paradigm is auditable active abstraction and supervisory control, exemplified by frontier systems that reached 100.00 RHAE on the 25-game public set—specifically NVIDIA's Agentic Variation Operators (AVO), Tycho's active abstraction over deterministic rendered Moore machines, Kepler's complete-history retrodiction and pre-action commit verification, and AERA's entropy-driven Speed–Depth Pareto trade-off.

A forensic examination of the empirical gap between early community scores (~12%–30%) and frontier public-set saturation (60%–100%) demonstrates that neither raw language model scale nor unverified Python improvisation is sufficient on unseen private games. Purely reactive language agents hallucinate causal rules, repeat no-op or fatal cycles, and exhaust their action budgets before discovering multi-mechanic compositions. Conversely, eager programmatic world-model synthesis that forces the agent to write a full simulator on every turn burns wall-clock compute and stalls when observations contain hidden state or quantized UI timers.

To close the gap toward 100% RHAE on out-of-distribution private games without smuggling in forbidden hand-crafted game heuristics, this blueprint specifies Archimedes-3: a zero-heuristic, hierarchical, active-inference neurosymbolic architecture built directly atop the Franzen/Duck baseline. Archimedes-3 treats internal model deliberation, Python sandbox execution, retrodiction verification, and counterfactual rollouts as cheap epistemic operations that incur zero RHAE penalty, while treating every environment action as a scarce experimental intervention governed by Bayesian Optimal Experiment Design (BOED) and a supervisory anti-stagnation controller modeled on NVIDIA AVO.

## 2. ARC-AGI-3 Problem Formalization

### 2.1 Environment Topology and Scoring Mechanics Brief

ARC-AGI-3 comprises 135 hand-crafted, turn-based 2D grid environments partitioned into a 25-environment public demonstration set (containing 183 total levels), a semi-private validation set, and a fully private evaluation set (55 environments in the Kaggle code competition split). Each environment $e \in D$ is structured as an ordered sequence of levels $l \in \{1, 2, \dots, L_e\}$ that progressively compose underlying mechanics without providing textual instructions, rule sheets, cultural symbols, letters, numbers, or explicit objective signals. All tasks are grounded purely in four Core Knowledge priors: objectness (cohesion, persistence, continuity), geometry and topology (symmetry, connectivity, enclosure), intuitive physics (contact causality, obstruction, momentum), and goal-directed agency. Every environment passes an automated qualification regime verifying that a 50,000-step random policy cannot solve a level more often than 1 in 10,000 attempts ($p_{\text{rand}} \le 10^{-4}$).

At each discrete decision turn $t$, the environment emits an observation consisting of either a single settled frame $F_t \in \{0, 1, \dots, 15\}^{64 \times 64}$ or a transient non-interactive animation sequence $\mathbf{F}_t = (F_{t,1}, F_{t,2}, \dots, F_{t,m_t})$ terminating in the actionable settled frame $F_t = F_{t,m_t}$. The agent selects an action $a_t$ from an environment-specific legal subset $\mathcal{A}_e \subseteq \{\text{ACTION1}, \dots, \text{ACTION5}, \text{ACTION6}(x,y), \text{ACTION7}, \text{RESET}\}$, where ACTION1–ACTION5 represent discrete directional or control keys, ACTION6 selects a grid coordinate $(x, y) \in \{0, \dots, 63\}^2$, ACTION7 executes an undo reverting to the prior state (where enabled), and RESET re-initializes the current level.

The official competition objective maximizes the macro-averaged Relative Human Action Efficiency ($T$) across the evaluation portfolio $D$, inspired by the robotics navigation Success weighted by Path Length (SPL) metric:

$$T = \frac{1}{|D|} \sum_{e \in D} E_e$$

Within each environment $e$ having $L_e$ levels, the environment score $E_e$ is a linearly weighted average of per-level efficiency scores $S_{l,e}$, where later levels carry weight proportional to their index $w_{l,e} = \frac{l}{\sum_{k=1}^{L_e} k} = \frac{2l}{L_e(L_e+1)}$:

$$E_e = \sum_{l=1}^{L_e} w_{l,e} \, \mathbb{I}(\text{completed}_{l,e}) \, S_{l,e}$$

In a 5-level environment, Level 1 contributes $1/15$ of the environment score, Level 2 contributes $2/15$, Level 3 contributes $3/15$, Level 4 contributes $4/15$, and Level 5 contributes $5/15$; completing only the first four levels caps the maximum possible environment score at $10/15 = 66.7\%$ regardless of how efficiently Levels 1–4 were solved. For each completed level $l$, let $h_{l,e}$ denote the human action baseline—defined officially as the upper-median best human action count (or second-best out of 10 human testers on first exposure, selecting the upper middle entry for even counts to filter out lucky speed-run outliers)—and let $a_{l,e}$ denote the cumulative state-altering actions expended by the agent on level $l$ across all attempts (excluding the initial unscored RESET that instantiates the play). The per-level score is capped at $1.15$ prior to or during squaring to prevent a single shortcut from dominating the aggregate:

$$S_{l,e} = \min\left(1.15, \frac{h_{l,e}}{a_{l,e}}\right)^2$$

Internal operations that do not alter the environment—such as Python tool calls, internal deliberation steps, world-model simulations, and syntax-repair retries—do not increment $a_{l,e}$. However, any submitted environment command—including no-ops that fail to move an entity, exploratory probes, actions taken prior to a fatal reset, and ACTION7 undo steps—increments $a_{l,e}$ if it is sent to the game server. If $a_{l,e}$ reaches the hard ceiling $B_{l,e} = 5 h_{l,e}$ without achieving the terminal win state, the level terminates with $S_{l,e} = 0$, and because progression is sequential, all subsequent levels $k > l$ in environment $e$ remain locked and score zero.

## 3. Baseline Forensics: Franzen / Duck Harness

### 3.1 Lineage: From StochasticGoose and TAAF Duck to Franzen Milestone 2

The evolution of the leading open-source Kaggle architecture follows a clear empirical trajectory. During the 2025 ARC-AGI-3 Agent Preview Competition, Tufa Labs (Dries Smit and Jack Cole) won first place (12.58% on private games, completing 18 levels) with StochasticGoose, a 4-layer convolutional neural network trained online from scratch on each level via binary cross-entropy to predict whether an action (state, action) would cause any pixel in the $64 \times 64$ frame to change. While frame-change prediction prevented wasted no-op actions and oriented local exploration, it lacked semantic world modeling or goal inference.

For ARC Prize 2026 Milestone 1, Tufa Labs pivoted to The Duck (taaf-duck-harness), winning first place by placing an open-weight language model (Qwen 3.6 27B FP8) inside an interactive Python read-eval-print loop (REPL). Crucially, Tufa Labs discovered that supplying rigid, hand-crafted domain tools degraded model performance; allowing the language model to write arbitrary Python code to inspect grids, test hypotheses, and emit action batches proved superior.

Daniel Franzen's Milestone 2 winning repository (`da-fr/arc-agi-3-solution`, mirrored and extended in `sofiantarek2009-hash/ARC-Agent`) forked the Duck harness and achieved a $>20\times$ score increase (from 1.21% in Milestone 1 to 27.9% official Milestone 2 open-source winner, and up to 36.73% on subsequent runs) through five structural upgrades: migrating the backbone to Qwen3.8-Flash-Next (W4A16 quantization with Multi-Token Prediction drafting) served on SGLang, exposing intermediate animation frames and visual diffs, adding no-op and border-bar guards plus ACTION7 undo integration, retaining agent-authored Python helper functions in the sandbox namespace across turns, and introducing a cache-aware cross-game priority scheduler.

### 3.2 Forensic Decomposition of the Franzen / Duck Repository

A file-by-file forensic analysis of the Franzen/Duck repository (`ARC3-Inference` and `taaf-duck-harness-kaggle-share.ipynb`) reveals the exact operational mechanics of its six core subsystems. First, the actual control loop implements an asynchronous, multi-stream observe–deliberate–execute-python–act–observe cycle across active game environments. At each turn, the runner constructs a multimodal and text prompt containing the system instructions, rolling interaction history, structured frame diffs, and available legal actions. The language model generates an internal deliberation trace followed by Python code blocks executed inside a persistent per-game sandbox (`RuntimeState`). Within this Python sandbox, the agent inspects numpy representations of the $64 \times 64$ grids, invokes helper utilities, and queues one or more environment actions. When the queued action batch is flushed to the ARC-AGI-3 environment wrapper, execution halts immediately if a level transition, game-over reset, or guard trigger occurs.

Second, the perception pipeline exposes multiple complementary views of the $64 \times 64 \times 16$ state: exact integer and character matrices in Python, upscaled RGB board images with cell gridlines for visual alignment, frame-difference matrices highlighting exact coordinates (r, c) where color $c_{t-1} \neq c_t$, intermediate animation frame buffers captured between decision steps, game-over terminal frames preserved prior to auto-reset, and connected-component object segmentation utilities that group orthogonally or diagonally adjacent cells of identical or non-background colors. Third, the action interface and guard subsystem allows actions (ACTION1–ACTION7, RESET) to be emitted singly or as a planned sequence batch. To prevent catastrophic budget hemorrhage under the quadratic RHAE penalty, Franzen implemented no-op and repeat bookkeeping guards: if an action produces zero interior board changes (explicitly excluding border UI timer and budget bars), that (state_hash, action) pair is flagged as a known no-op, aborting remaining repeated actions in the batch and returning a structured warning to the model.

Fourth, the world-model and context retention mechanism avoids forcing the agent to maintain a rigid JSON schema or summarized text scratchpad; instead, Franzen expanded the rolling conversation history window and enabled the retained-function mechanism, whereby Python functions defined by the agent (such as custom pathfinders, entity trackers, or rule evaluators) persist in the sandbox globals across turns and levels within the same game. Fifth, the compute scheduler addresses the strict Kaggle wall-clock ceiling across dozens of games by replacing naive round-robin execution with a dynamic priority formula. Each game stream $e$ receives a priority score factoring in the immediate level weight $w_{l,e}$, remaining unlocked levels, actions expended $a_{l,e}$ relative to budget, cumulative generated tokens, and a time-based exponential fading penalty when a stream consumes thousands of tokens without completing a level. Crucially, the scheduler limits the number of concurrently active streams so that active games remain resident in SGLang's RadixAttention KV cache and Gated DeltaNet recurrent state cache. Sixth, the serving stack deploys Qwen3.8-Flash-Next (125B main MoE parameters with 6B active per token, 51B N-gram embedding table, 4B MTP drafter) quantized to W4A16 (or NVFP4/FP8 depending on accelerator) via SGLang with prefix caching, chunked prefill, and speculative decoding enabled.

### 3.4 Baseline Failure Taxonomy and Headroom Map

Despite winning Milestone 2, the Franzen baseline exhibits substantial run-to-run variance ($\mu = 25.77, \sigma = 3.93$ across identical Kaggle submissions) and leaves over 70% of the RHAE leaderboard score uncaptured. Forensic trace analysis reveals eight interconnected failure modes that account for this lost headroom. First, the baseline suffers from unverified multi-action batch execution: the language model frequently emits a batch of 5 to 15 actions based on an unverified mental simulation, and when step 2 encounters an unexpected obstruction or dynamic entity movement, steps 3 through 15 execute blindly, burning the action budget or causing death. Second, the agent exhibits epistemic stagnation and hallucinated rules: when a hypothesis fails, the model often fixates on minor variations of the same falsified theory across 20 or more turns, lacking an external supervisory monitor (such as NVIDIA AVO's Supervisor) to force a hypothesis-space reset. Third, the system lacks complete-history retrodiction: when the agent revises a rule on turn 15, it checks the new rule only against the immediate transition from turn 14 to 15, forgetting that turn 3 to 4 directly contradicts the revision.

Fourth, the serving layer is vulnerable to SGLang speculative-decoding and tool-parser instabilities: under high concurrency or specific tool-call parser flags (`--tool-call-parser qwen3_coder` with thinking enabled), Qwen3.8-Flash-Next can suffer speculative acceptance collapse (`spec_accept_length` dropping to 0.0 or 1.0) or deterministic token-0 loops, silently slashing effective throughput by 50% to 70%. Fifth, perception relies on static connected-component segmentation, which merges distinct adjacent objects of the same color and splits multi-colored composite objects, corrupting object persistence tracking. Sixth, the baseline lacks a formal exploration-to-exploitation switching criterion—such as AERA's belief entropy $\mathcal{H}(b_t)$ or Tycho's render coverage $\text{cov}(\hat{\rho})$—to govern when to stop probing and commit to a shortest-path solver. Seventh, on level transitions, the agent suffers from cross-level over- and under-transfer, either discarding validated mechanics or blindly assuming that a secondary level-specific rule from Level 1 remains unchanged in Level 3. Eighth, when the rolling context hits the window limit and trims early turns, prefix-cache eviction shifts the entire token prefix, triggering an expensive 20+ second cold re-prefill of the 128K–256K context window.

## 4. Literature Landscape and Source Map

### 4.1 Synthesis of Foundational and Frontier Research

Constructing a domain-general fluid-intelligence architecture requires synthesizing findings across intelligence theory, cognitive science, world modeling, program induction, active exploration, and high-performance inference systems. In foundational intelligence theory, François Chollet's formalization (*On the Measure of Intelligence*) defines intelligence not as zero-shot skill possession on known tasks, but as skill-acquisition efficiency: the conversion ratio of prior knowledge plus experience into new capability over unfamiliar problem distributions. While Marcus Hutter's universal artificial intelligence (AIXI) and Legg-Hutter intelligence formalize optimal reinforcement learning over computable environments weighted by Solomonoff's universal prior $P(\mathcal{M}) \propto 2^{-K(\mathcal{M})}$, exact AIXI is incomputable; practical interactive agency requires resource-rational analysis and bounded optimality (Simon; Russell & Subramanian; Lieder & Griffiths), where an agent optimizes expected external utility subject to bounded internal computational capacity (tokens and wall-clock time). In cognitive architecture theory, classical symbolic production systems such as ACT-R (Anderson), SOAR (Laird, Newell, & Rosenbloom), Sigma, and CLARION separate working memory buffers, long-term procedural productions, and declarative episodic/semantic stores, while Baars's Global Workspace Theory and Dehaene's conscious workspace model explain how modular perceptual specialists broadcast salient prediction errors to a capacity-limited central serial workspace. Complementing symbolic architectures, Karl Friston's Free Energy Principle and Active Inference formalize biological agency as minimizing variational free energy (prediction error) and expected free energy—which naturally decomposes into pragmatic value (goal attainment) and epistemic value (information gain)—mirroring Elizabeth Spelke's Core Knowledge developmental framework (objectness, geometry, intuitive physics, and goal-directed agency) and Alison Gopnik's "scientist in the crib" theory of causal intervention in children.

On static ARC benchmarks (ARC-AGI-1 and ARC-AGI-2), early brute-force domain-specific language (DSL) search gave way to test-time training (TTT / TTFT), deep refinement loops, and synthetic data scaling. In ARC Prize 2025 (ARC-AGI-2), NVIDIA's winning NVARC team (Ivan Sorokin and Jean-François Puget, 24.03% private / 29.72% public) demonstrated that combining a 4-stage Synthetic Data Generation (SDG) pipeline (103,000 synthetic puzzles and 3.2 million augmented puzzles) with the ARChitects' 2D perspective-scored masked-diffusion refinement and Alexia Jolicoeur-Martineau's 7M-parameter Tiny Recursive Model (TRM) (which achieved 45% on ARC-AGI-1 and 8% on ARC-AGI-2 via test-time gradient descent without pretraining) outperformed systems costing 40 times more. Similarly, Daniel Franzen's ICML 2025 work (*Product of Experts with LLMs: Boosting Performance on ARC is a Matter of Perspective*) established the power of geometric invariance and log-likelihood aggregation across dihedral transformations. Simultaneously, evolutionary agent harnesses like RoboPhD (`optimize_anything()`) showed that evolving a 22-line seed agent into a 1,013-line multi-strategy system raised ARC accuracy from 27.8% to 65.8%.

In the domain of world models and object-centric representation, pixel-latent reinforcement learning models—including Ha and Schmidhuber's World Models, PlaNet, Dreamer, DreamerV2, DreamerV3 (Hafner et al.), SimPLe, MuZero (Schrittwieser et al.), EfficientZero, EfficientZero V2, TD-MPC, TD-MPC2 (Hansen et al.), LeCun's JEPA, and action-conditioned video models such as DeepMind's Genie/Genie 2, ActionRoPE, ActionSplice, ActWorld, AlayaWorld, and CausalDreamer—require thousands of trajectories to learn continuous latent dynamics. By contrast, ARC-AGI-3 demands zero-shot model construction within 10 to 50 discrete actions. Object-centric representations (Locatello et al.'s Slot Attention, Kipf et al.'s SAVi, Elsayed et al.'s SAVi++, and Singh et al.'s STEVE) demonstrate that factoring visual scenes into discrete entity slots with amodal persistence dramatically accelerates relational generalization. To achieve immediate sample efficiency, neurosymbolic program induction—pioneered by Ellis et al.'s DreamCoder (Wake-Sleep library learning), Tsividis et al.'s EMPA, Ahmed et al.'s TheoryCoder, Tang et al.'s WorldCoder, and formalized for ARC-AGI-3 by Tycho (Lehmann, Aioanei, and Vahdati, 2026) and Kepler (Wu, 2026)—represents environment dynamics as explicit, executable Python transition functions over deterministic rendered Moore machines with transition emissions, ascending Judea Pearl's three-level causal hierarchy from passive association ($\mathcal{L}_1: P(y \mid x)$) to active intervention ($\mathcal{L}_2: P(y \mid do(x))$) and counterfactual deduction ($\mathcal{L}_3: P(y_{x'} \mid x, y)$).

In active exploration and agentic verification, AERA (Han, 2026) proved that under RHAE's quadratic scoring, an agent faces a convex Speed–Depth trade-off between minimizing actions (Speed) and maximizing information gain per action (Depth, measured in nats/action of belief-entropy reduction $\Delta \mathcal{H}(b)$), synthesizing Lindley's Bayesian Optimal Experiment Design (BOED) with intrinsic curiosity (Pathak et al.'s ICM, Burda et al.'s RND, BYOL-Explore, and empowerment). Early reactive explorers like StochasticGoose (Smit & Cole, 2025) used CNN frame-change prediction as a universal orientation signal, while Blind Squirrel (Dick, 2025) mapped deterministic state-transition graphs. ### 5.2 What Would It Take to Mimic AGI in ARC-AGI-3?

Mimicking general fluid intelligence in ARC-AGI-3 does not require pre-encoding human cultural knowledge, which the benchmark explicitly excludes; rather, it requires closing ten structural gaps between autoregressive text generation and empirical scientific agency. First, perception-to-concept formation must bridge the chasm between pixels and objects: raw $64 \times 64$ integer matrices lack intrinsic entity boundaries, so when a sprite translates two cells rightward, pixel-level correlation sees 30 cells mutate color simultaneously, whereas object-centric abstraction compresses the transition into a single translation vector $\Delta \mathbf{p} = (0, +2)$ of a persistent entity $o_i$, enabling zero-shot transfer when level layouts change. Second, autonomous goal discovery must operate without instructions by detecting structural asymmetries: locked topological chambers becoming reachable, finite sets of homologous objects being decremented toward zero, geometric templates approaching symmetry completion, or level-transition events confirming terminal conditions.

Third, causal model building via intervention is indispensable because passive observation cannot distinguish whether object $A$ moves due to key ACTION1 or due to an autonomous background timer; only controlled interventions ($do(a_t)$)—including deliberate comparisons between actions or ACTION7 undo-and-branch probes—isolate true causal mechanisms. Fourth, counterfactual simulation allows the agent to query its internal transition model prior to committing an irreversible environment action, asking what state $\hat{s}_{t+1}$ would occur if ACTION3 were executed instead of ACTION2, thereby preventing fatal collisions and wasted actions. Fifth, compositional generalization addresses the core source of ARC-AGI-3 difficulty—the composition of multiple mechanics across levels—by factoring the world model into modular, entity-typed transition clauses rather than monolithic level scripts, so previously verified rules compose automatically when co-instantiated in late levels.

Sixth, transfer with discrimination recognizes that within a single game $e$, core physics persist across levels $1 \dots L_e$ while initial layouts and secondary hazards evolve, whereas across different games $e_1 \neq e_2$, zero mechanics may be assumed to transfer. Enforcing hard cross-game sandbox isolation alongside soft Bayesian cross-level prior inheritance prevents catastrophic negative transfer while preserving within-game learning. Seventh, uncertainty-aware decision-making requires the world model to distinguish cells it can deterministically predict from cells governed by unmodeled mechanics by returning explicit abstention $\perp$, preventing both reckless long-horizon plans and timid over-probing. Eighth, abductive self-correction ensures that when observation $F_{t+1}$ violates prediction $\hat{F}_{t+1}$, the agent does not hallucinate excuses in prose, but mechanically halts execution, logs the counterexample transition $(F_t, a_t, F_{t+1})$, isolates the broken rule clause, and repairs `world_model.py` until 100% retrodiction consistency is restored. Ninth, resource-rational cognition dynamically trades internal compute for external action efficiency, spending extra seconds of Python search whenever doing so saves even a single environment action on high-weight late levels. Tenth, continual in-game learning accumulates irreversible competence from turn 1 to turn $T$ via append-only episodic graphs and verified programmatic rules without catastrophic forgetting.

### 6.2 Multi-Scale Segmentation and Amodal Persistence Tracking

In the Franzen baseline, object segmentation relies on static monochrome connected components ($4$- or $8$-connectivity). This approach fails whenever two distinct objects of the same color touch (merging into one component) or when a single entity comprises multiple colors (splitting into fragments). Archimedes-3 replaces static segmentation with a three-tier Spatiotemporal Object-Centric State Estimator (SOCSE) implemented in the Python runtime.

In the first tier, Multi-Connectivity Topological Decomposition, the background color $c_{\text{bg}}$ for each settled frame $F_t \in \{0, \dots, 15\}^{64 \times 64}$ is inferred via maximum border and area support plus structural invariance across turns. The foreground is decomposed simultaneously into monochrome 4-connected components $\mathcal{C}_4(F_t)$, monochrome 8-connected components $\mathcal{C}_8(F_t)$, and multi-color cohesive patches $\mathcal{C}_{\text{comp}}(F_t)$ defined as non-background contiguous regions bounded by $c_{\text{bg}}$ or rectangular frames. For every extracted component, SOCSE computes the Euler characteristic (number of enclosed holes and cavities), bounding box $[r_{\min}, r_{\max}] \times [c_{\min}, c_{\max}]$, center of mass $\boldsymbol{\mu}_i$, exact pixel mask $M_i$, rotational and reflective symmetry group ($D_4$ dihedral classification), and translation-invariant canonical bitmask shape hash $h_{\text{shape}}(M_i)$.

In the second tier, Motion-Coherent Split/Merge Resolution (Amodal Tracking), tentative object identities $o_i \in \mathcal{O}_t$ are matched across consecutive frames $F_{t-1} \to F_t$ and across intermediate animation sub-frames $F_{t,1}, \dots, F_{t,m_t}$ via minimum-cost bipartite matching (the Hungarian algorithm) over a distance metric combining rigid translation $\Delta \mathbf{p}$, shape-hash conservation, and color histogram conservation. When two adjacent components of different colors $c_a, c_b$ translate by the exact same non-zero vector $\Delta \mathbf{p} \neq \mathbf{0}$ across multiple steps, their joint cohesion posterior $P(\text{composite}(o_a, o_b) \mid \tau_{1:t})$ updates toward 1, binding them into a single composite entity. Conversely, when a tracked entity $o_i$ with canonical bitmask $M_i$ moves adjacent to an identically colored static region $o_j$ and their monochrome component merges into $M_{ij} = M_i \cup M_j$, SOCSE performs template-guided de-merging by subtracting the known static mask $M_j$ and verifying the translation of $M_i$, thereby preserving the distinct identities of $o_i$ and $o_j$ under contact or partial occlusion.

In the third tier, HUD and Monotonic Counter Invariant Separation, SOCSE generalizes Franzen's border budget-bar guard by scanning all 1D linear strips (horizontal or vertical rows of uniform width, whether on the border or in the interior) whose pixel count changes monotonically by a constant step $\Delta k \in \{-1, +1, \dots\}$ on every action regardless of action type ACTION1–ACTION6. Such components are typed as `MonotonicCounter` / `HUD_Indicator` with posterior probability $P(\text{HUD}(o_i) \mid \tau_{1:t})$. This prevents the agent from misinterpreting a shrinking action-budget bar as an approaching hazard or a valid exploratory state change.

$$\mathcal{M}_l = (S_l, s_{l,0}, \mathcal{A}_e, T_\theta, \rho_\theta, \omega_\theta, \upsilon_\theta)$$

In this tuple, $S_l$ denotes the latent state space encoding both visible grid entities and hidden variables (such as internal counters, toggle states, velocities, object inventories, or occluded tiles beneath a moving entity). The state initialization function $s_{l,0} = \iota_\theta(F_{l,0}, l)$ maps the level's initial rendered frame $F_{l,0}$ and level index $l$ to the initial latent state. ### 7.3 Programmatic World-Model Workbench and Complete-History Retrodiction

Rather than maintaining $\theta$ merely as fragile natural-language prose inside the conversation history, Archimedes-3 instantiates an auditable Programmatic World-Model Workbench (`world_model.py`) in the Python sandbox, synthesizing the best mechanisms of Tycho and Kepler. Every candidate hypothesis $\theta_k$ is an executable Python class implementing `init_state(frame_0, level_idx)`, `transition(state, action)`, `render(state)`, and `predict_outcome(state)`. Whenever the agent updates or proposes $\theta_k$, the harness automatically runs Complete-History Retrodiction, replaying the entire append-only transition tape $\tau_{1:t} = \{(F_0, a_0, F_1, \upsilon_1), \dots, (F_{t-1}, a_{t-1}, F_t, \upsilon_t)\}$ collected across all attempts on the current level (and optionally prior levels of game $e$) through $\theta_k$.

For each historical transition $\tau_j$, the harness computes three diagnostic metrics:
1. **Interior Render Accuracy** $\text{Acc}(\theta_k, \tau_j)$, defined as the fraction of non-abstained ($\hat{\rho}_{r,c} \neq \perp$) interior cells where $\hat{\rho}(\hat{s}_{j+1})_{r,c} == (F_{j+1})_{r,c}$;
2. **Dynamic Change Recall** $\text{Rec}_{\Delta}(\theta_k, \tau_j)$, defined as the fraction of cells that actually changed between $F_j$ and $F_{j+1}$ that were non-abstained and correctly predicted by $\hat{\rho}(\hat{s}_{j+1})$, which prevents a trivial model that abstains on all moving objects ($\hat{\rho} = \perp$ everywhere except static walls) from claiming 100% accuracy; and
3. **Canonical Coverage** $\text{cov}(\theta_k) = \frac{1}{4096} \sum_{r,c} \mathbb{I}(\hat{\rho}(\hat{s})_{r,c} \neq \perp)$.

The workbench maintains a portfolio of $K \le 3$ top competing programmatic hypotheses $\{\theta_1, \theta_2, \theta_3\}$ ranked by a Minimum Description Length (MDL) Bayesian posterior that penalizes program complexity $|\theta_k|$ (measured in abstract syntax tree nodes) while rewarding exact retrodiction of dynamic cell deltas.

## 8. Goal Inference and Utility Design

### 8.1 Autonomous Goal Discovery Without Instructions

In ARC-AGI-3, the agent receives zero intermediate reward signals until the exact frame on which a level is completed. Furthermore, private games are explicitly designed to foil static heuristics such as "always walk to the green square". Archimedes-3 treats the goal condition $G \in \mathcal{G}$ as a latent boolean predicate over states $G: S_l \to \{0, 1\}$ inferred via a structural Bayesian posterior $P(G \mid \tau_{1:t})$ grounded in five Core Knowledge invariants.

First, Structural Motif and Symmetry Completion ($G_{\text{sym}}$) detects partial geometric patterns, unmatched reference templates (such as a miniature $N \times N$ legend grid displayed in a corner chamber alongside an incomplete $k N \times k N$ canvas), or broken dihedral symmetries where translating or toggling movable entities restores exact isomorphism $d_{\text{iso}}(M_{\text{canvas}}, M_{\text{template}}) \to 0$. Second, Topological Alignment and Target Coincidence ($G_{\text{align}}$) identifies pairs of entities $(o_{\text{ctrl}}, o_{\text{target}})$ that share rare morphological signatures—such as identical interior hole topology, complementary concave and convex bounding shapes, or matching color palettes—where reducing geodesic distance $d_{\text{geo}}(o_{\text{ctrl}}, o_{\text{target}}) \to 0$ is initially obstructed by intermediate barriers. Third, Homologous Set Exhaustion ($G_{\text{exhaust}}$) tracks interactions between the controllable entity $o_{\text{ctrl}}$ and members of a homologous object class $\mathcal{C}_k = \{o_{k,1}, \dots, o_{k,m}\}$; when contact causes $o_{k,j}$ to vanish or mutate while incrementing a status indicator or opening a barrier, the posterior shifts toward exhausting the finite set $|\mathcal{C}_k(s)| \to 0$.

Fourth, Reachable-Space Expansion ($G_{\text{reach}}$) evaluates the set of grid coordinates $\mathcal{R}(s) \subset \{0, \dots, 63\}^2$ reachable by $o_{\text{ctrl}}$ under verified movement dynamics without triggering fatal states; any state transition that removes an obstruction separating $\mathcal{R}(s_t)$ from a previously unreachable enclosed topological chamber $\mathcal{R}_{\text{locked}}$ receives high subgoal progress weight ($\Delta |\mathcal{R}(s)| > 0$). Fifth, Cross-Level Terminal Transfer ($G_{\text{transfer}}$) exploits positive ground-truth supervision the instant Level 1 transitions to Level 2 upon action $a_{T_1}$: the Goal Inference module filters $\mathcal{G}$ to retain only predicates $G$ that evaluate to True on the winning state $s_{1, T_1}$ and False on all prior states $s_{1, 0 \dots T_1-1}$, transferring this concentrated posterior directly to Level 2 alongside a novelty-adaptation prior for newly introduced entity types.

### 8.2 Score-Aware Multi-Component Utility Function

Every candidate state $s'$ evaluated during simulation or exploration is scored by the composite utility function:

$$U(s' \mid b_t) = w_g P(\text{goal} \mid s', b_t) + w_p P(\text{progress} \mid s', b_t) - w_r P(\text{death} \mid s', b_t) - w_a \mathbb{E}[\Delta a \mid s', b_t] + w_i I(s'; \mathcal{M} \mid b_t)$$

In this formulation, $P(\text{goal} \mid s', b_t) = \sum_{G \in \mathcal{G}} P(G \mid b_t) \, G(s')$ represents the expected terminal win probability under the current belief state $b_t$, while $P(\text{progress} \mid s', b_t)$ measures normalized subgoal advancement (such as fractional increase in reachable space $|\mathcal{R}(s')|/|\mathcal{R}_{\text{total}}|$, reduction in template edit distance, or decrement in homologous target count). The term $P(\text{death} \mid s', b_t)$ captures the probability of triggering a fatal reset as estimated from the Fatal-Action Ledger and $\upsilon_\theta(s')$. The action-cost expectation $\mathbb{E}[\Delta a \mid s', b_t]$ represents the expected remaining actions to reach $G$, weighted by the magnitude of the marginal derivative of the RHAE objective $\left|\frac{\partial S_{l,e}}{\partial a_{l,e}}\right| = \frac{2 h_{l,e}^2}{a_{l,e}^3}$. Finally, $I(s'; \mathcal{M} \mid b_t)$ quantifies the expected Shannon mutual information between the observed transition into $s'$ and the unknown model parameters $(\theta, G)$.

## 9. Active Exploration and Experiment Selection

### 9.1 The Speed–Depth Pareto Frontier and RHAE-Aware Acquisition

As formalized in AERA (Han, 2026), RHAE's quadratic form $S_{l,e} = \min(1.15, h_{l,e}/a_{l,e})^2$ imposes a strict second-order penalty on deviations from the Pareto frontier $\mathcal{F}_E$ between Speed (minimizing total actions $a_{l,e}$) and Depth (maximizing average information gain per exploratory action $\Delta \mathcal{H}(b) / a_{\text{explore}}$ in nats/action). If an agent commits to a plan prematurely while belief entropy $\mathcal{H}(b_t)$ is high, the plan fails and wastes 10 to 30 actions; conversely, if the agent over-explores after the mechanics are sufficiently determined, each redundant probe directly erodes $(h_{l,e}/a_{l,e})^2$.

Archimedes-3 selects exploratory interventions by maximizing an RHAE-calibrated acquisition function over legal actions $a \in \mathcal{A}_e$:

$$A(a \mid b_t) = \lambda_1(t) \, \mathbb{E}[\text{GoalProgress}(a \mid b_t)] + \lambda_2(t) \, \text{IG}(a \mid b_t) - \lambda_3(t) \, \text{Risk}(a \mid b_t) - \lambda_4(t) \, \text{ActionCost}(a \mid a_{l,e}, h_{l,e})$$

Here, the Information Gain term $\text{IG}(a \mid b_t)$ combines Jensen-Shannon Divergence (JSD) Disagreement across competing world-model hypotheses $\{\theta_1, \dots, \theta_K\}$ with Novel Affordance Probing:

$$\text{IG}(a \mid b_t) = \text{JSD}\Big(\hat{\rho}_{\theta_1}(T_{\theta_1}(s_t, a)), \dots, \hat{\rho}_{\theta_K}(T_{\theta_K}(s_t, a))\Big) + \beta_{\text{novel}} \, \mathbb{I}\big(\text{untested\_interaction}(s_t, a)\big) \cdot P(\Delta F_{\text{interior}} \neq \mathbf{0} \mid s_t, a)$$

where $P(\Delta F_{\text{interior}} \neq \mathbf{0} \mid s_t, a)$ is a fast online frame-change predictor—inspired by StochasticGoose and Franzen's no-op ledger—that suppresses zero-information no-op actions, and $\text{untested\_interaction}(s_t, a)$ identifies actions that bring the controllable entity into first contact with an unprobed object class $\mathcal{C}_m$ or test an unexecuted legal action key.

## 10. Planning, Search, and Counterfactual Verification

### 10.1 Why Language-Only Imitation Wastes Actions and Explicit Search Is Mandatory

When a language model plans a 12-step trajectory purely inside its autoregressive token stream, minor spatial indexing errors—such as miscounting a corridor length by 1 cell or forgetting that a patrolling entity advances simultaneously on each step—compound exponentially. In ARC-AGI-3, an off-by-one coordinate error causes the agent either to collide with a wall (wasting actions on no-ops) or to step onto a hazard (triggering a level reset that wipes out all prior progress on that attempt while keeping every expended action on the RHAE bill). Explicit search over an executable Python transition function `world_model.transition(s, a)` eliminates spatial arithmetic errors completely.

### 10.2 Two-Level Hierarchical Planner: Options + Belief-Space A\* / PUCT

Archimedes-3 employs a two-level hierarchical planner inside the Python workbench. At the upper level, the Strategic Subgoal Planner operates over the relational scene graph using candidate macro-options $\Omega = \{\omega_1, \dots, \omega_m\}$ that are synthesized dynamically from the learned ontology rather than hardcoded. These induced macro-options encompass:
- $\omega_{\text{nav}}(o_{\text{ctrl}}, \mathbf{p}_{\text{target}})$ to navigate the controllable entity to coordinate $\mathbf{p}_{\text{target}}$ while avoiding states $s$ where $\upsilon_\theta(s) = \text{DEATH}$;
- $\omega_{\text{contact}}(o_{\text{ctrl}}, o_j, \text{dir})$ to bring $o_{\text{ctrl}}$ into orthogonal contact with entity $o_j$ from direction $\text{dir}$ to test or trigger an interaction rule;
- $\omega_{\text{displace}}(o_j, \mathbf{p}_{\text{dest}})$ to push or pull a movable entity $o_j$ to target coordinate $\mathbf{p}_{\text{dest}}$ via topological routing; and
- $\omega_{\text{click}}(o_j)$ to execute ACTION6(r, c) on the centroid $(r, c) \in M_j$ of entity $o_j$.

At the lower level, the Exact Solver selects between State-Equivalence A\* Search and Belief-Space PUCT depending on world-model certainty. When the world model is deterministic and high-coverage ($\text{Rec}_{\Delta} \ge 0.90$), the workbench executes State-Equivalence A\* Search over `world_model.transition(s, a)` using a canonical state deduplication hash $h_{\text{canon}}(s)$ that masks out monotonic HUD timer bars. Masking HUD timers during state hashing is essential: if a 64-cell timer decrements on every step, identical spatial configurations at $t=2$ and $t=4$ possess different raw pixel hashes, causing naive BFS or FSM graphs to treat loop revisits as brand-new states. By hashing only the interior canonical state $s_{\text{interior}}$ while tracking the remaining action budget $b_{\text{rem}}$ as a resource constraint, A\* finds the guaranteed shortest action sequence in milliseconds. Conversely, when multiple competing hypotheses $\{\theta_1, \theta_2, \theta_3\}$ remain plausible ($0.50 \le \text{Rec}_{\Delta} < 0.90$), the planner runs Belief-Space PUCT (Predictor + Upper Confidence Bound applied to Trees) over the ensemble of transition models, selecting action sequences that either reach the goal across all hypotheses (robust plans) or branch at a diagnostic state that maximally splits the ensemble.

### 10.3 Pre-Action Commit Verification and Surprise-Triggered Plan Repair

Following Kepler's auditable commit contract and AERA's surprise abort, Archimedes-3 never flushes an unverified multi-action batch blindly to the server. Before executing a planned sequence $\pi = (a_1, a_2, \dots, a_m)$, the Pre-Action Commit Gate records the sequence of predicted canonical renders $(\hat{F}_1, \hat{F}_2, \dots, \hat{F}_m)$ and predicted terminal outcomes $(\hat{\upsilon}_1, \dots, \hat{\upsilon}_m)$. As each step $a_k$ ($k = 1 \dots m$) is submitted to the environment, returning actual observation $F_k$ and animation sequence $\mathbf{F}_k$, the harness immediately evaluates the Surprise Predicate on all non-abstained interior cells:

$$\text{Surprise}(F_k, \hat{F}_k) = \mathbb{I}\Big( \exists (r,c) \in \text{Interior}: \hat{F}_{k,r,c} \neq \perp \land \hat{F}_{k,r,c} \neq F_{k,r,c} \Big) \lor \mathbb{I}(\upsilon_k \neq \hat{\upsilon}_k)$$

Whenever $\text{Surprise}(F_k, \hat{F}_k) == 0$, the subsequent action $a_{k+1}$ executes immediately in Python without invoking an expensive language model generation call, saving substantial wall-clock time and token budget. The instant $\text{Surprise}(F_k, \hat{F}_k) == 1$, the remaining queue $(a_{k+1}, \dots, a_m)$ is aborted immediately before a single additional environment action is wasted. Control returns to the Abductive Fault Localizer, which logs the counterexample $(F_{k-1}, a_k, F_k)$ and repairs the world model.

## 12. Epistemic Controller and Compute Allocation

### 12.1 Intra-Game Metacognitive Orchestrator and Supervisory Intervention

A major discovery of Tycho (Lehmann et al., 2026) is that forcing an agent to build or repair a programmatic world model automatically on every failure (trigger policy) wastes substantial inference compute on edge cases, whereas allowing an orchestrator policy to decide when constructing or repairing the model is worth its cost achieves 100.00 RHAE with significantly higher efficiency. Similarly, NVIDIA AVO demonstrated that a separate Supervisor monitoring the broader trajectory for stagnation or repetitive cycles is essential to redirect the agent when progress stalls.

At every decision cycle, Archimedes-3's Epistemic Controller evaluates a Value-of-Computation (VoC) policy over six discrete cognitive operations. When a verified plan $\pi^*$ is currently executing and $\text{Surprise}(F_t, \hat{F}_t) == 0$, the controller selects **Direct Fast-Path Execution**, emitting the next planned action in under $5\text{ms}$ of CPU time without calling the language model. During Phase I or II when $\text{Rec}_{\Delta} < 0.85$ and an informative untested interaction is immediately adjacent, the controller invokes a **1-Step Epistemic Probe** using a lightweight deliberation budget (`max_thinking_tokens = 4,096`) to select the highest-acquisition probe $a^* = \arg\max_a A(a \mid b_t)$. Once three or more informative transitions have accumulated since the last model update, or whenever a pre-action commit check fails ($\text{Surprise} == 1$), the controller escalates to **Workbench Model Synthesis and Repair** (`max_thinking_tokens = 16,384–32,768`), synthesizing or repairing `world_model.py` against the complete retrodiction tape.

Immediately upon `world_model.py` reaching $\text{Rec}_{\Delta} \ge 0.90$ with a candidate goal predicate $G$ having posterior $P(G \mid b_t) \ge 0.50$, the controller triggers **Symbolic Planner Invocation**, executing Python A\* or PUCT search to emit a verified path. If retrodiction fails on a transition that contained $m_t > 1$ animation sub-frames, the controller schedules a **Re-Perception and Animation Audit**, instructing the workbench to inspect the sub-frame trajectory arrays $\mathbf{F}_t$. Finally, an independent **NVIDIA AVO Supervisory Intervention** watchdog tracks the Stagnation Index $Z_t$, defined as the number of consecutive model turns or environment actions elapsed without discovering a new canonical state cluster in `StateGraph`, increasing `world_model.py` retrodiction recall $\text{Rec}_{\Delta}$, or expanding reachable space $|\mathcal{R}(s_t)|$. If $Z_t \ge 4$ turns (or $\ge 8$ actions), the Supervisor intercepts the prompt and injects a mandatory **Paradigm Shift Directive**: it locks the current dominant hypothesis $\theta_1$ into `SUSPENDED` status, surfaces the top unprobed objects and actions from the Episodic Ledger, and requires the agent to formulate an orthogonal hypothesis before another environment action is permitted.

### 12.2 Global Portfolio Scheduler (All-Games Mandate)

Under the Kaggle competition constraint—where 55 private games must be solved within a fixed wall-clock window $B_{\text{wall}}$—greedily running one game to completion before starting the next is catastrophic: a single deceptive game can consume 45 minutes while leaving 15 solvable games untouched. Conversely, switching games on every turn thrashingly evicts SGLang's KV cache and GDN states across all 55 streams.

Archimedes-3 upgrades Franzen's priority scheduler into a Cache-Pinned Portfolio Value-of-Computation Scheduler. Let $M_{\text{active}}$ be the maximum number of concurrent game streams that fit comfortably inside SGLang's GPU KV cache and host-pinned GDN state pool without eviction (typically $M_{\text{active}} \in \{4, 6\}$ depending on context depth). Only games in the active working set $\mathcal{W}_t$ ($|\mathcal{W}_t| = M_{\text{active}}$) execute turns. Whenever a game in $\mathcal{W}_t$ completes, hits its action budget ceiling, or triggers a Supervisory Stagnation cooldown, it is swapped out for the highest-priority waiting game $e^* \in D \setminus \mathcal{W}_t$ according to the marginal expected RHAE rate:

$$\text{Priority}(e, t) = \frac{\mathbb{E}[\Delta E_e \mid b_{e,t}]}{\mathbb{E}[\Delta \tau_{\text{compute}}(e \mid b_{e,t})]} + \nu_{\text{explore}}(e) - \psi_{\text{switch}}(e \notin \mathcal{W}_t)$$

Specifically, the numerator decomposes expected environment score gain across the current level $l$ and remaining unlocked levels $k = l+1 \dots L_e$:

$$\mathbb{E}[\Delta E_e \mid b_{e,t}] = \widehat{P}_{\text{solve}}(l \mid b_{e,t}) \left[ w_{l,e} \min\left(1.15, \frac{\hat{h}_{l,e}}{a_{l,e} + \hat{a}_{\text{rem}}(l)}\right)^2 + \gamma_{\text{unlock}} \sum_{k=l+1}^{L_e} w_{k,e} \, \bar{S}_{\text{prior}}(k) \right] \cdot \exp\left(-\frac{\text{tokens\_since\_progress}_{e}}{\tau_{\text{fade}}}\right)$$

In this scheduling law, $\widehat{P}_{\text{solve}}(l \mid b_{e,t})$ increases monotonically with verified world-model recall $\text{Rec}_{\Delta}(e)$, reachable-space progress, and remaining action budget fraction $1 - \frac{a_{l,e}}{5 \hat{h}_{l,e}}$. The term $\gamma_{\text{unlock}} \sum_{k=l+1}^{L_e} w_{k,e} \bar{S}_{\text{prior}}(k)$ captures the option value of unlocking later levels: because level $L_e$ carries $L_e$ times the weight of level 1, solving level 3 of a 6-level game unlocks $15/21 = 71.4\%$ of the total environment weight. The factor $\exp(-\text{tokens\_since\_progress}_e / \tau_{\text{fade}})$ preserves Franzen's exponential compute-fading damper, smoothly de-prioritizing games that burn tokens without raising $\text{Rec}_{\Delta}$ or completing levels. Finally, $\psi_{\text{switch}}(e \notin \mathcal{W}_t)$ provides a cache-locality hysteresis bonus that keeps resident streams in $\mathcal{W}_t$ for at least a minimum quantum (such as 4 turns or until level completion or stagnation) so SGLang prefix caches are never thrashingly evicted.

## 16. Self-Verification, Falsification, and Recovery

### 16.1 Grounded Empirical Falsification vs. Uncalibrated LLM Confidence

A central finding of Kepler (Wu, 2026) is that private deliberation confidence is deeply unreliable: a language model will frequently declare "High Confidence (95%)" in prose while proposing an action sequence that contradicts an observation recorded ten turns earlier. Furthermore, Kepler proved that zero wrong predictions can mask zero prediction coverage—if a model abstains everywhere or fails to execute, it makes zero errors while providing zero guidance.

Archimedes-3 grounds verification strictly in deterministic environment transitions via a four-stage Falsification and Recovery Pipeline:
1. **Pre-Action Prediction Commitment**: Before any planned action $a_t$ is sent to the game server, the active `world_model.py` must commit a predicted next state $\hat{s}_{t+1} = T_\theta(s_t, a_t)$, a partial render $\hat{F}_{t+1} = \rho_\theta(\hat{s}_{t+1})$ with explicit dynamic coverage $\text{cov}_{\Delta} > 0$, and a predicted terminal status $\hat{\upsilon}_{t+1}$.
2. **Post-Action Error Classification (Abductive Fault Localization)**: Upon receiving actual observation $(F_{t+1}, \mathbf{F}_{t+1}, \upsilon_{t+1})$, the harness computes the cell-wise discrepancy tensor $\mathcal{E}_{t+1} = F_{t+1} \ominus \hat{F}_{t+1}$ over non-abstained cells and classifies any surprise into one of five disjoint root causes:
   - **Type A (Unexpected No-Op)**: $F_{t+1,\text{interior}} == F_{t,\text{interior}}$ when $\hat{F}_{t+1} \neq F_t$, diagnosing an unmodeled solid obstruction, boundary limit, or exhausted movement precondition and updating `NoOpLedger` immediately.
   - **Type B (Localized Entity Kinematics Error)**: Background and static structures match, but entity $o_i$ landed at $\mathbf{p}_{\text{actual}} \neq \mathbf{p}_{\text{pred}}$ (for example, sliding 3 cells instead of 1, or bouncing off a surface), localizing repair exclusively to the kinematic update method of class $\mathcal{C}(o_i)$.
   - **Type C (Unmodeled Contact or Non-Local Side Effect)**: Entity $o_i$ moved as predicted, but a distant cell or secondary object $o_k$ mutated unexpectedly (such as a switch opening a distant barrier), triggering a relational dependency scan linking the contact event $(o_i, o_j)$ at $t$ to the mutated object $o_k$ at $t+1$.
   - **Type D (Latent State or History-Dependent Aliasing)**: The exact same visible frame $F_t$ and action $a_t$ previously produced $F'$ on turn $t_1$, but now produced $F'' \neq F'$ on turn $t_2$. As formalized in Tycho's rendered Moore machine theory, this mathematically proves the existence of a hidden state variable $h_t \in S_l \setminus \text{obs}(F_t)$ (such as an internal charge, parity toggle, or invisible step counter). The workbench automatically augments state with a latent register initialized in `init_state` and updated along the transition path between $t_1$ and $t_2$.
   - **Type E (Unpredicted Fatal Termination)**: $\upsilon_{t+1} == \text{DEATH}$ when $\hat{\upsilon}_{t+1} == \text{PLAYABLE}$. The harness captures the game-over frame $F_{t+1,\text{term}}$, distinguishes whether death resulted from a spatial collision in the interior grid or from a `MonotonicCounter` HUD bar reaching zero (Franzen's budget-bar distinction), and records the exact precondition in `FatalLedger`.
3. **Level-Transition Audit**: When $\upsilon_{t+1} == \text{WIN}$ advances the environment from level $l$ to $l+1$, the verifier executes a Cross-Level Schema Diff: it identifies which object colors and shapes from level $l$ recur in $F_{l+1,0}$ (preserving their verified transition methods with prior weight $0.85$) and isolates novel colors and shapes present in $F_{l+1,0}$ as high-priority epistemic targets for Phase II probing.

## 17. Training, Adaptation, and Synthetic-Task Strategy

### 17.1 Offline Compositional Synthetic Pretraining (NVARC-3 Pipeline)

While the Kaggle competition forbids internet access during evaluation, teams may upload pre-trained open-weight checkpoints or LoRA adapters as Kaggle datasets. In ARC Prize 2025, NVARC (Sorokin & Puget, NVIDIA) proved that pre-training models on a 4-stage Synthetic Data Generation (SDG) pipeline of 103,000 compositional puzzles produced a commanding first-place victory.

To adapt NVARC's methodology to interactive ARC-AGI-3 environments without encoding public-game heuristics, Archimedes-3 defines an offline Procedural Moore-Machine Synthetic Generator (NVARC-3 SDG):
- **Stage 1 (Primitive Operator Library)**: Samples 2 to 4 abstract Core-Knowledge transition operators from a broad mathematical grammar (2D translations, raycast reflections, cellular connectivity rules, modulo counters, topological portals, and symmetry completions).
- **Stage 2 (Compositional Moore-Machine Synthesis)**: The sampled operators are composed into a random deterministic Python Moore machine $\mathcal{M}_{\text{syn}}$ on a $64 \times 64 \times 16$ grid, verifying programmatically that the generated level is solvable in $5 \le h \le 40$ actions and cannot be solved by a 50,000-step random walk ($p_{\text{rand}} < 10^{-4}$, matching ARC-AGI-3's official qualification filter).
- **Stage 3 (Interaction Trace and Retrodiction Trajectory Generation)**: Exploratory interaction traces $\tau_{1:k}$ are paired with the exact ground-truth Python `world_model.py` that explains $\tau_{1:k}$ and the optimal A\* action sequence.
- **Stage 4 (RLVR / SFT Adapter Tuning)**: A lightweight LoRA adapter on Qwen3.8-Flash-Next (or Qwen3.8-27B) is fine-tuned using Reinforcement Learning from Verifiable Rewards (RLVR), where the verifiable reward is exact retrodiction accuracy $\text{Rec}_{\Delta}(\theta) == 1.0$ on held-out transitions of $\mathcal{M}_{\text{syn}}$. Because the synthetic machines are procedurally generated from abstract mathematical topologies rather than public games, this sharpens the model's general ability to write bug-free `world_model.py` simulators without overfitting to the 25 public games.

### 17.2 Test-Time Adaptation Within the Evaluation Container

During live Kaggle evaluation, gradient-based weight updates across a 176B MoE model are prohibitively expensive in VRAM and wall-clock time. Instead, Archimedes-3 performs Non-Parametric In-Context and Programmatic Test-Time Adaptation (TTA) through two complementary mechanisms. Second, Evolutionary Program Refinement evolves `world_model.py` across turns within each game using execution-guided synthesis, treating every observed environment transition as a unit test in an expanding verification suite.

## 21. Mathematical Specification

### 21.1 Belief State, Observation Model, and Transition Posterior

Every equation in Archimedes-3 directly governs an executable module in the control loop. Let the agent's epistemic belief state at turn $t$ on level $l$ of environment $e$ be the joint posterior distribution over the programmatic transition hypothesis $\theta \in \Theta$, the latent Moore-machine state $s_t \in S_l$, and the terminal goal predicate $G \in \mathcal{G}$, conditioned on the complete interaction history $\tau_{1:t} = \{(F_0, a_0, \mathbf{F}_1, F_1, \upsilon_1), \dots, (F_{t-1}, a_{t-1}, \mathbf{F}_t, F_t, \upsilon_t)\}$:

$$b_t(\theta, s_t, G) = P(\theta, s_t, G \mid \tau_{1:t}) = P(s_t \mid \theta, \tau_{1:t}) \, P(\theta \mid \tau_{1:t}) \, P(G \mid \theta, \tau_{1:t})$$

Because the underlying Moore machine $\mathcal{M}_l(\theta)$ is deterministic given $\theta$, the latent state trajectory $\hat{s}_{1:t}(\theta)$ is determined recursively from $\hat{s}_0 = \iota_\theta(F_0, l)$ via $\hat{s}_{j+1}(\theta) = T_\theta(\hat{s}_j(\theta), a_j)$. The observation likelihood $p(o_{j+1} \mid \hat{s}_j, a_j, \theta)$ over settled frame $F_{j+1}$, animation sequence $\mathbf{F}_{j+1}$, and terminal status $\upsilon_{j+1}$ incorporates Tycho's partial-render abstention $\perp$ with an MDL coverage prior:

$$\ln p(o_{j+1} \mid \hat{s}_j, a_j, \theta) = \sum_{(r,c) \in \text{Int}} \Big[ \mathbb{I}(\hat{\rho}_{r,c} \neq \perp) \ln \big((1-\epsilon)\mathbb{I}(\hat{\rho}_{r,c} = F_{j+1,r,c}) + \epsilon\big) + \mathbb{I}(\hat{\rho}_{r,c} = \perp) \ln \alpha_{\perp}(r,c) \Big] + \ln p(\upsilon_{j+1} \mid \hat{\upsilon}_{j+1})$$

where $\epsilon = 10^{-6}$ sharply penalizes any false deterministic claim on an interior cell, and $\alpha_{\perp}(r,c) \in (0, 1)$ penalizes abstaining on cells that actually changed ($F_{j+1,r,c} \neq F_{j,r,c}$) more heavily than static background cells, forcing $\theta$ to explain dynamic deltas rather than trivially returning $\perp$.

Combined with a Minimum Description Length (MDL) simplicity prior $p_0(\theta) \propto \exp(-\lambda_{\text{MDL}} \, \text{AST\_Complexity}(\theta))$, the hypothesis posterior update over the complete history $\tau_{1:t+1}$ is:

$$p(\theta \mid \tau_{1:t+1}) = \frac{p(o_{t+1} \mid \hat{s}_t(\theta), a_t, \theta) \, p(\theta \mid \tau_{1:t})}{\sum_{\theta' \in \Theta_t} p(o_{t+1} \mid \hat{s}_t(\theta'), a_t, \theta') \, p(\theta' \mid \tau_{1:t})} \propto p_0(\theta) \prod_{j=0}^{t} p(o_{j+1} \mid \hat{s}_j(\theta), a_j, \theta)$$

### 21.2 Information Gain, Exploration–Execution Trade-Off, Credit Assignment, and Distribution Shift

For any candidate action $a \in \mathcal{A}_e$, the expected Information Gain $\text{IG}(a \mid b_t)$ is the expected Kullback-Leibler divergence between the posterior belief $b_{t+1}$ after observing $o' \sim p(o' \mid b_t, a)$ and the current belief $b_t$, which equals the mutual information $I(\Theta, \mathcal{G}; O_{t+1} \mid b_t, a)$:

$$\text{IG}(a \mid b_t) = \mathbb{E}_{o' \sim p(o' \mid b_t, a)} \Big[ D_{\text{KL}}\big( b_{t+1}(\cdot \mid b_t, a, o') \,\big\|\, b_t \big) \Big] = \mathcal{H}\big(p(o' \mid b_t, a)\big) - \sum_{\theta \in \Theta_t} p(\theta \mid b_t) \, \mathcal{H}\big(p(o' \mid \hat{s}_t(\theta), a, \theta)\big)$$

To directly optimize the competition objective $T$ across the Exploration–Execution Trade-Off, define the expected score-aware Q-value $Q(b_t, a)$ in units of environment RHAE points:

$$Q(b_t, a) = \mathbb{E}_{o', b_{t+1} \mid b_t, a} \left[ w_{l,e} \, \Delta \widehat{\text{RHAE}}_l(b_{t+1}, a_{l,e}+1) + \lambda_{\text{future}} \, V_{\text{future}}(b_{t+1}, a_{l,e}+1) \right]$$

where $V_{\text{future}}$ includes both the remaining value on level $l$—driven by information gain $\text{IG}(a \mid b_t)$ reducing expected future execution actions $\mathbb{E}[\hat{a}_{\text{rem}}(b_{t+1})]$—and the unlocked option value of subsequent levels $\sum_{k=l+1}^{L_e} w_{k,e} \bar{S}_k$. Incorporating explicit hazard and action-waste penalties yields the risk-adjusted action value executed by the policy:

$$\tilde{Q}(b_t, a) = Q(b_t, a) - \gamma_{\text{death}}(a_{l,e}) \, P(\upsilon_{t+1} = \text{DEATH} \mid b_t, a) - \eta_{\text{noop}}(a_{l,e}) \, P(\text{wasted\_action} \mid b_t, a)$$

Here $\gamma_{\text{death}}(a_{l,e})$ scales monotonically with actions already spent on the current attempt ($a_{\text{attempt}}$): a fatal reset on turn 1 loses only 1 action, whereas a fatal reset on turn 18 after completing 90% of a level wipes out 18 actions of progress and forces the agent to spend another 18 actions re-executing the path, cutting $(h_{l,e}/a_{l,e})^2$ by at least fourfold.

Furthermore, formal Credit Assignment upon level completion ($\upsilon_T == \text{WIN}$) separates epistemic credit from execution credit: an exploratory transition $\tau_j$ receives epistemic credit proportional to its realized Kullback-Leibler divergence $D_{\text{KL}}(b_{j+1} \parallel b_j)$ that falsified incorrect hypotheses and enabled the winning `world_model.py`, whereas execution actions receive credit only if they lie along the minimum-length geodesic path $\pi^*$ in the canonical state graph `StateGraph` between $s_{l,0}$ and $s_{l,T}$. Coincidental transitions that neither reduced hypothesis entropy along the winning rule branch nor advanced along $\pi^*$ receive zero credit, preventing the reinforcement of spurious correlations. Under Distribution Shift between the 25 public games and the 55 private games, any policy parameter tied to surface color or static layout coordinates suffers unbounded regret on private games, whereas invariant relational operators verified via complete-history retrodiction maintain bounded generalization error across arbitrary private topologies.

### 21.3 Global Compute-Constrained Portfolio Optimization

Across the full evaluation portfolio $D$ under wall-clock budget $B_c$ and per-level action ceiling $a_{l,e} \le 5 h_{l,e}$, the global meta-policy $\pi^* = (\pi_{\text{act}}^*, \pi_{\text{think}}^*, \pi_{\text{sched}}^*)$ solves:

$$\pi^* = \arg\max_{\pi} \mathbb{E}_{\pi} \left[ \frac{1}{|D|} \sum_{e \in D} \sum_{l=1}^{L_e} \frac{2l}{L_e(L_e+1)} \, \mathbb{I}(a_{l,e} \le 5 h_{l,e} \land \text{solved}_{l,e}) \min\left(1.15, \frac{h_{l,e}}{a_{l,e}}\right)^2 \right] \quad \text{s.t.} \quad \sum_{e \in D} \sum_{t} c_{\text{wall}}(e, t) \le B_c$$

### 22.2 Statistical Evaluation Protocol and Variance Control

Community replications of Franzen's Milestone 2 notebook on Kaggle established a crucial statistical baseline: across identical unchanged submissions, the leaderboard score exhibits a mean of $\mu = 25.77$ and a single-draw standard deviation of $\sigma = 3.93$ (coefficient of variation $\approx 15\%$). Consequently, a single submission scoring $+3.0$ points above baseline lies within $0.76\sigma$ and cannot be distinguished from random seed noise. To prevent public-set overfitting—warned against by both AERA and Kepler—the 25 public games are partitioned into a 15-game Development Set (used for prompt and hyperparameter tuning) and a 10-game Frozen Local Holdout Set (never inspected during code development), supplemented by a 20-game Procedural Moore-Machine Synthetic Benchmark.

Every candidate module must be evaluated across $N = 4$ independent random seeds on the 25-game public suite, reducing the standard error of the mean to $\sigma_{\bar{x}} = \sigma / \sqrt{4} \approx 1.96$ RHAE points. A module is promoted to the competition branch only if it satisfies four strict criteria:
1. $\Delta \overline{\text{RHAE}} \ge +3.5$ points ($p < 0.05$ one-sided),
2. Late-level ($l \ge 3$) completion rate does not regress,
3. SGLang prefix-cache hit rate remains $\ge 92\%$, and
4. The module passes the Section 18.2 Anti-Heuristic Audit with zero game-specific rules. Any technique that decreases token throughput by $>15\%$ without increasing $\Delta \overline{\text{RHAE}}$ by $\ge +4.0$ points is immediately killed.

### 22.3 How to Close the Gap to 100% (Section 32 Mandate)

Closing the gap from early community baselines (~30%) to current Kaggle leaders (60%–70%) and ultimately toward 100% requires analyzing the exact mathematical bottlenecks of the RHAE decomposition:

$$\mathbb{E}[\text{RHAE}] = \mathbb{E}[\text{levels completed}] \times \mathbb{E}[\text{action efficiency} \mid \text{completed}] \times \mathbb{E}[\text{survival under time budget}]$$

Moving from a 30% system (such as Franzen Milestone 2 or AERA) to a 65%–70% system is governed primarily by late-level completion rate and eliminating catastrophic open-loop action batches. In a 5-level game, completing Levels 1 through 3 at $1.5\times$ human actions yields $(1/15 + 2/15 + 3/15) \times (1/1.5)^2 = \frac{6}{15} \times 0.444 = 17.8\%$ RHAE; simply unlocking and completing Levels 4 and 5 at the exact same $1.5\times$ efficiency raises the game score to $\frac{15}{15} \times 0.444 = 44.4\%$, and improving path efficiency to $1.15\times$ human actions via Python A\* raises it to $(1/1.15)^2 = 75.6\%$. Specifically, combining Qwen3.8-Flash-Next (with SGLang Issue #36537 and MTP wedging resolved) with Kepler's Pre-Action Commit Gate, Tycho's orchestrator programmatic world model, and NVIDIA AVO's Stagnation Supervisor directly addresses the failure modes that leave Levels 3 through 5 unsolved in the baseline.

Moving from a 65% system to a 90%–100% system—as demonstrated by NVIDIA AVO, Tycho, and Kepler on the 25 public games—requires near-zero redundant exploration on first exposure ($a_{l,e} \le h_{l,e}$ on 98.9% of levels, as Kepler achieved on 181 of 183 public levels with Claude Opus 5) alongside 100% level completion across all games. On the public set, frontier systems achieve this via massive cloud test-time compute (858M tokens in Kepler) and frontier coding backbones (Claude Opus 5, GPT-5.6 Sol, Gemini 4 Argon). Under the offline Kaggle competition constraints (open-weight Qwen3.8-Flash-Next W4A16/NVFP4, zero internet access, and an ~8–12 hour wall-clock ceiling across 55 unseen private games), claiming 100.0% RHAE would be scientifically unfounded because first-exposure exploration on genuinely novel private mechanics inevitably expends 10% to 35% more probing actions than the upper-median human baseline on a subset of games, and Qwen3.8-Flash-Next (6B active parameters) exhibits lower single-shot code-synthesis reliability than Claude Opus 5. However, the Expected-Score Decomposition projects that Archimedes-3 (Variant B + NVARC-3 LoRA) can realistically increase the Portfolio Level Completion Rate $\mathbb{E}[\text{completed}]$ from ~38% (Franzen M2) to $78\%–85\%$, and increase conditional action efficiency $\mathbb{E}[(h/a)^2 \mid \text{completed}]$ from ~0.68 to $0.84–0.90$ via HUD-masked A\* shortest-path execution and commit-gate abort, yielding a realistic expected Kaggle private-set score of $65.5\% \text{ to } 76.5\%$ RHAE—sufficient to challenge directly for first place on the official Kaggle leaderboard.

## 24. Prioritized Research Roadmap and Build Order

To maximize expected hidden-leaderboard value within a disciplined engineering schedule, implementation proceeds across four sequential, verification-gated phases, supported by a transparent Research Log tracking what was inspected, what was established, and what remains to be experimentally verified.

### Phase 1: Serving Stability, Cache Residency, and Immediate Action Guards (Days 1–3)
The engineering priority is hardening SGLang serving for Qwen3.8-Flash-Next by configuring pinned host RAM for the 51B N-gram embedding table (`--enable-ple-host-pinning`), FP8 KV and QSA indexer caches, native XML `<python>` block extraction (eliminating `--tool-call-parser qwen3_coder`), and the concurrency and speculative-acceptance watchdog. Simultaneously, Phase 1 deploys the Kepler Pre-Action Commit Gate and Append-Only Context Manager—wrapping Franzen's action batcher so every multi-step sequence attaches a predicted interior frame trace $\hat{F}_{1:m}$ and halts instantaneously on the first cell mismatch ($\text{Surprise} == 1$) while pinning prompt prefixes to 512-block QSA boundaries—and generalizes Franzen's border-bar diff logic into `MonotonicCounter` HUD separation feeding `NoOpLedger` and `FatalLedger`.

### Phase 2: Auditable Programmatic World-Model Workbench and Symbolic Planner (Days 4–7)
The team constructs the Tycho/Kepler Workbench (`world_model.py` plus Complete-History Retrodiction) inside the Python sandbox via `workbench.register_model()`, grading agent-authored `init_state`, `transition`, and partial-abstention `render` ($\perp$) functions against the lossless `EpisodicTape` $\tau_{1:t}$ and returning exact first-failure cell diffs. This verified transition model is then connected directly to the State-Equivalence A\* and PUCT Planner (with HUD-timer masking in the canonical state hash) so solved mechanics immediately translate into human-optimal action counts ($a_{l,e} \le h_{l,e}$).

### Phase 3: Spatiotemporal Perception, Active Inference, and AVO Supervisor (Days 8–11)
Perception is upgraded to SOCSE and exact text-grid fusion, combining NVIDIA AVO's exact $64 \times 64$ text coordinate representation with motion-coherent split/merge tracking and compiled sub-turn animation event timelines. Phase 3 then integrates the AERA Speed–Depth BOED Prober alongside the lightweight 4-layer StochasticGoose CNN frame-change filter to guide 1-step Phase I/II probes and cost-thresholded ACTION7 undo recovery, and activates the NVIDIA AVO Supervisory Intervention watchdog ($Z_t \ge 4$) and Portfolio VoC Scheduler with late-level unlock option values.

### Phase 4: Offline Synthetic Moore-Machine Adaptation and Full Portfolio Validation (Days 12–14)
The complete system undergoes a 4-seed ablation suite across the 15-game dev split, 10-game frozen holdout split, and synthetic Moore machines to verify $\Delta \overline{\text{RHAE}} \ge +3.5$ per module and zero heuristic leakage. Finally, where offline GPU compute permits, 100,000 procedural Moore-machine trajectories are generated via the NVARC-3 SDG pipeline to fine-tune a rank-32 RLVR LoRA adapter for Qwen3.8-Flash-Next, maximizing single-shot code synthesis reliability for the final Kaggle private evaluation.
